# Marketing Workspace

This folder is the current working set for launch marketing.

## What the app is

Verity Protect is a family-first call screening app for older adults, caregivers, and families. Calls are routed to a Verity number first. Unknown callers are asked for a 6-digit Safety PIN. Trusted contacts skip the PIN and connect directly. Calls that do not clear screening can fall into voicemail/review, and family members can see alerts, call history, transcripts, and shared activity in the app.
