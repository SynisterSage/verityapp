# Writer Targets

Updated: 2026-03-10

This is a first-pass outreach list built from public contact pages, public author pages, and public newsroom instructions.

## How to use this list

- Start with `Tier 1` first.
- Customize the subject line and first sentence for each outlet.
- Do not blast every contact with the exact same email.
- Use your strongest angle for each group:
  - Aging/caregiving outlets: older-adult safety, caregiver peace of mind
  - Business/tech outlets: young founder, product differentiation, fraud-tech angle
  - Local outlets: hometown founder, App Store launch, family-origin story
